<b>Проектування бази данних <<Лікарняні записи пацієнтів>></b>
<p>Мета системи: 
    створення системи для запису пацієнтів та керуванння медичними рецептами</p> 
<p>Зацікавлені сторони: лікарі які відстежують дату прийому пацієнта</p>
<p>Пацієнти можуть подивитись інформацію про лікря та пеерглянути рецепт після прийому</p>
<p>Дані для зберігання:</p>
<p> дата прийому</p>
<p> інформація про пацієнта</p>
<p> кабінет</p>
<p> рецепт ліків</p>
<p> інформація про лікаря</p>
<p> <b>Бізнес-правила</p>
<p> одночасно на прийомі може бути один пацієнт  та один лікар</p>
<p> пацієнт після прийому повинен отрмати рекомендаії(рецепт)</p>
<p> опис ER діаграми</p>
<p>Пацієнт: ID в системі, ПІБ, дата народження та номер телефону </p>
<p>Доктор: ID в системі, ПІБ, спеціалізація, кабінет</p>
<p>Прийом: PK ID в системі,FK ID пацієнта, FK ID доктора, FK дата  </p>
<p>Рецепт: PK ID в системі, FK ID прийому,  FK ліки та дозування  </p>
<p>Звязки:</p>
<p>в одного доктора може бути багато прийомів</p>
<p>в одого пацієнта може бути багато прийомів</p>
<p>в одного прийома може бути багато рецептів</p>
